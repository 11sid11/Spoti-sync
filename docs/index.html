HOW IT WORKS

One sidebar. Four choices. Done.

1

Install

Paste the Spoti Sync bundle into a Google Sheet's bound Apps Script project.

2

Open

Reload the Sheet and choose Spoti Sync → Open Spoti Sync.

3

Connect

Use the sidebar to configure your Spotify Developer app and authorize Spotify.

4

Add a job

Choose source, target, behavior and automation. Save.

5

Done

Spoti Sync keeps the automation in your Google account and records status in the Sheet.

THE JOB MODEL

Only the choices that matter.

SourceLiked Songs
or Spotify playlist
TargetExisting playlist
or create new
BehaviorExact Mirror
or Append Only
AutomationOff · Hourly · Every N hours
Daily · Every N days

Hour-based jobs are checked hourly, but Spotify is contacted only when a job is actually due. Optional per job: keep the target playlist description updated with the latest successful sync time.

INSTALL

From blank Sheet to first sync.

The website only builds the Apps Script bundle. Spoti Sync itself runs inside the Google Sheet you create.

  1. 1
    Create a blank Google Sheet

    Open sheets.new.

  2. 2
    Open Apps Script

    Choose Extensions → Apps Script and replace the contents of Code.gs.

  3. 3
    Paste and save

    Use the bundle from this page, then reload the Sheet.

  4. 4
    Open Spoti Sync

    Choose Spoti Sync → Open Spoti Sync.

  5. 5
    Connect Spotify and add a job

    The sidebar shows the Redirect URI, guides connection, and lets you create the first job.

UPDATE

Keep your Sheet. Replace only the code.

Latest: stable

Use the same bound Apps Script project so your Spotify connection, jobs, playlist IDs, Activity history and automation state stay in place.

Updates are intentionally not installed silently. You choose when to replace the Apps Script bundle.

  1. Open the existing Sheet → Extensions → Apps Script.
  2. Replace Code.gs with the latest bundle and save.
  3. Reload the Sheet.
  4. Open Spoti Sync → Open Spoti Sync.

PRIVACY

Your automation stays in your accounts.

Spoti Sync runs in your Google Apps Script environment. Spotify tokens are stored in Apps Script User Properties — not on a hosted Spoti Sync backend or this GitHub Pages site.
