Make Spotify playlists follow your Liked Songs.

UPDATE AN EXISTING INSTALLATION

Keep the installation. Replace only the code.

Spoti Sync checks GitHub for release metadata automatically. When an update is available, replace the Apps Script bundle in your existing installation. Your Spotify Client ID, OAuth tokens, configured playlist IDs, and scheduler remain with the same Sheet/script project.

Download latest

  1. Open your existing Sheet → Extensions → Apps Script.
  2. Replace all contents of Code.gs with the latest bundle and Save.
  3. Reload the same Sheet.
  4. Run Spoti Sync → Initialize / Repair Sheets once.

For the 1.3 sheet redesign, Initialize / Repair migrates the current job configuration into Dashboard, Jobs, Schedule, and Activity. You do not need to paste your Spotify Client ID or target playlist IDs again.

Updates are intentionally not installed silently. The running script checks only a small version metadata file. You explicitly replace the code so repository changes cannot silently rewrite Apps Script in your Google account.

GUIDED SETUP

Install in a few deliberate steps.

Nothing runs on your laptop after setup. The only code you install is the generated Apps Script bundle from this repository.

Your setup progress0 of 7 complete

  1. Create a blank Google Sheet

    This Sheet becomes your Spoti Sync installation and holds non-sensitive job configuration and activity.

    Create blank Sheet

  2. Open Apps Script

    In the Sheet, choose Extensions → Apps Script. Delete the default contents of Code.gs.

  3. Paste the Spoti Sync bundle

    Copy the generated bundle below, paste it into Code.gs, and press Save.

    Download file

  4. Reload the Sheet and open Setup

    Reload the spreadsheet. A Spoti Sync menu appears. Choose Spoti Sync → Setup and review Google's requested permissions.

  5. Create your Spotify Developer app

    The Setup sidebar shows your installation's Redirect URI. Create a Spotify app, add that exact URI, select Web API, and copy its Client ID.

    Open Spotify Developer Dashboard

  6. Connect Spotify and add jobs

    Paste the Client ID into Setup and authorize Spotify. Then use Spoti Sync → Add Sync Job.

    Shareable mirrorLIKED_SONGS → MIRROR → targetFrequency: daily
    Append-only archiveLIKED_SONGS → APPEND → targetFrequency: every 10 days

  7. Preview, sync, then enable automation

    Run Preview Enabled Jobs first. If the changes look right, run Sync Now, then enable the daily scheduler.

    The Schedule sheet shows scheduler health and upcoming jobs. The Activity sheet shows past runs. After every successful job, the target playlist description also gets a compact heartbeat such as Kept fresh with Spoti Sync ✨ · sid.is-a.dev · Synced Saturday at 2:22 AM. Spotify requires the authorized account to own the playlist for description changes; if that cosmetic update is rejected, the music sync still succeeds and Activity records a warning.

    Done. Google Apps Script runs in your account even when your devices are off.

SYNC BEHAVIOR

Predictable by design.

Exact Mirror
Target Spotify tracks have the same managed membership as the source. Missing tracks are added; obsolete tracks are removed. Unsupported local files/episodes are left alone.
Append Only
Only missing source tracks are appended. Nothing already in the target is removed.
One scheduler
A single daily trigger checks all jobs. Longer intervals do not create additional Google triggers.
Playlist heartbeat
Every successful job updates the target playlist description in the same execution. A zero-change verification still refreshes the timestamp. Spoti Sync never changes the playlist name.
Update checks
The scheduler checks a small GitHub version metadata file at most once per day and never silently replaces executable code.

PRIVACY & SECURITY

No central credential store.

OAuth + PKCE

No Spotify client secret is required. Refresh/access tokens stay in Apps Script User Properties.

Liked Songs stays read-only

Spoti Sync intentionally does not request Spotify's library-modification scope, so it cannot unlike tracks.

Explicit targets only

Playlist-item and description writes are limited to playlist IDs configured as job targets.

Inspectable activity

Job state, scheduler health, bounded activity, and warnings remain visible in your own spreadsheet.

Minimal heartbeat data

The Spotify description contains only Spoti Sync wording, sid.is-a.dev, and the last successful sync time — no tokens or library data.

TROUBLESHOOTING

Common setup issues.

The Spoti Sync menu did not appear

Make sure the bundle was saved in the Apps Script project bound to the same Sheet, then reload the spreadsheet tab.

Spotify says the redirect URI is invalid

Use the exact Redirect URI shown in Spoti Sync → Setup.

A playlist returns HTTP 403

Use a target playlist your authorized Spotify account owns and can modify.

Why did my custom playlist description disappear?

Spoti Sync 1.3 manages the description of configured target playlists as its sync heartbeat. Playlist names are never changed.

Why is the heartbeat time older than expected?

The timestamp is the last successful job completion. If the playlist sync fails, Spoti Sync deliberately leaves the previous successful description in place.

Can I share one installation between multiple Spotify accounts?

Use a separate Sheet/Apps Script copy for each primary Google + Spotify account so OAuth tokens and triggers remain unambiguous.

Why doesn't Spoti Sync install updates by itself?

Silent self-modification would broaden the trust boundary. Spoti Sync checks version metadata and asks you to explicitly replace the bundle.
